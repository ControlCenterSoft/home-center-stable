# Home Center 0.56.0 — состав и проверка релиза

Публичный Stable-релиз 0.56.0 содержит Linux runtime-архив, source-архив, SPDX 2.3 SBOM, acceptance record, release manifest, `SHA256SUMS` и отдельный SHA-256 sidecar для runtime-архива.

Перед установкой проверьте, что версия релиза — `0.56.0`, опубликованный тег — `v0.56.0`, а имена и контрольные суммы артефактов согласованы с release manifest и `SHA256SUMS`. Runtime-архив также имеет файл `home-center-0.56.0-linux-amd64.tar.gz.sha256`.

Важно: checksum-sidecar доказывает целостность конкретного файла, но не доказывает совместимость его внутренней структуры с node-updater. Опубликованный runtime-архив v0.56.0 предшествует исправлению archive-shape контракта fail-closed updater и задним числом не изменяется. Поэтому для чистой установки 0.56.0 используйте официальный source-архив и штатный `deploy/scripts/install.sh` согласно [INSTALL.md](INSTALL.md), а для обновления следуйте ограничениям [UPGRADE.md](UPGRADE.md). Исправленный runtime publication contract относится к последующим квалифицированным Stable-релизам.

Официальными признаками публичного выпуска являются согласованные VERSION/release identity, опубликованные артефакты, checksums, SBOM, acceptance record и release manifest. Внутренняя организация разработки, служебные ветки, внутренние репозитории и идентификаторы процессов разработки не являются частью пользовательской продуктовой документации и не требуются для установки или эксплуатации Home Center.

Публикация новой версии не означает автоматическую активацию на существующем сервере. Обновление выполняется только после preflight, проверки резервной копии, совместимости конкретного update path, целостности артефактов и готовности rollback/recovery-пути.

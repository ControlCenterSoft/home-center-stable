# Home Center 0.56.0 — состав и проверка выпуска

Текущий официальный Public Stable — **0.56.0** с tag `v0.56.0`.

Публичный release set содержит:

- `home-center-0.56.0-linux-amd64.tar.gz`;
- `home-center-0.56.0-linux-amd64.tar.gz.sha256`;
- `home-center-0.56.0-source.tar.gz`;
- `SHA256SUMS`;
- acceptance evidence;
- release manifest;
- SPDX SBOM.

Перед установкой или обновлением проверяйте, что версия, tag, имена артефактов, checksums и release manifest относятся к одной release identity. Архивы также содержат собственные сведения о версии/ревизии и внутренний manifest целостности; несовпадение считается блокирующим условием.

Опубликованный `v0.56.0` и его артефакты являются неизменяемой исторической release identity и не должны переписываться задним числом документационными или последующими техническими изменениями.

## Особенность runtime-архива 0.56.0

В 0.56.0 присутствует отдельный SHA-256 sidecar, поэтому прежняя проблема отсутствующего checksum-sidecar к текущему Stable не относится. Однако форма опубликованного runtime-архива 0.56.0 предшествует исправлению контракта для fail-closed node-updater. Не обходите проверки updater и не подменяйте 0.56.0 пересобранным артефактом. Для чистой установки используйте поддерживаемый source/install path из [INSTALL.md](INSTALL.md); исправленный runtime publication contract применяется к последующим квалифицированным Stable-выпускам.

Наличие более новой функции, ветки или сборки само по себе не меняет Public Stable. Новый Stable считается доступным только после отдельной квалификации и официальной публикации полного release set.

# Конфигурация

Скопируйте подходящий пример из `deploy/config` и замените **все** демонстрационные значения.

Текущая закрытая схема `home-center.config.v5` описывает identity кластера и узлов, management addresses, Web- и peer-порты, пути state/backup, хранилище локального администратора, опциональную directory-аутентификацию, TLS-файлы, границу внешнего доступа и от нуля до 63 явно заданных peer endpoints.

Для поэтапного обновления runtime также принимает legacy single-peer конфигурацию Home Center 0.14 формата `home-center.config.v4`. Этот формат предназначен только для совместимого перехода; для актуальной multi-node конфигурации используйте v5. Адреса из `192.0.2.0/24` и имена в `example.invalid` являются только документационными примерами и не должны переноситься в реальную установку.

Профиль v1 в `deploy/profiles` является двухузловым примером. Профиль v2 в `deploy/examples` демонстрирует переносимую модель планирования для 1–64 узлов. Не включайте автоматический failover, пока для конкретного deployment не доказан независимый fencing design и соответствующий recovery path.

# Конфигурация Home Center

Возьмите подходящий пример из `deploy/config` и замените **все** демонстрационные значения перед использованием. Текущая закрытая схема `home-center.config.v5` описывает cluster/node identity, management addresses, Web/peer ports, пути состояния и backup, локального администратора, опциональную directory authentication, TLS-файлы, границу внешнего доступа и до 63 явно заданных peer endpoint.

Для поэтапного обновления runtime принимает также старую single-peer форму `home-center.config.v4`. Используйте её только в рамках поддерживаемого migration path и переведите конфигурацию на v5 до расширения peer topology.

Адреса из `192.0.2.0/24`, имена в `example.invalid` и другие демонстрационные значения являются только документационными примерами. Не копируйте их в рабочий контур без адаптации.

Профиль v1 в `deploy/profiles` — консервативный двухузловой пример. Профиль v2 в `deploy/examples` демонстрирует переносимое планирование для 1–64 узлов. Automatic failover должен оставаться отключённым, пока для конкретного deployment не доказаны fencing, quorum/data-safety и recovery.

Изменения network/external-access параметров должны проходить отдельный preflight с проверкой управляемости и rollback; публикация наружу не должна включаться неявно.

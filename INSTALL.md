# Home Center 0.56.0 — установка

Home Center 0.56.0 предназначен для Linux с systemd, Python 3.12 или новее и SQLite. Для сетевых интерфейсов управления необходимо использовать корректные TLS-сертификаты и закрытые ключи, предоставленные администратором.

## Какой артефакт использовать

Для **чистой установки 0.56.0** используйте официальный source-архив `home-center-0.56.0-source.tar.gz` из публичного Stable-релиза и сверяйте его SHA-256 по `SHA256SUMS`. После распаковки именно source-пакет содержит штатный `deploy/scripts/install.sh` и связанные deployment-файлы.

Опубликованный runtime-архив `home-center-0.56.0-linux-amd64.tar.gz` имеет отдельный `.sha256`, но выпуск 0.56.0 предшествует исправлению archive-shape контракта штатного fail-closed updater. Поэтому не используйте runtime-архив 0.56.0 как замену source-пакету для чистой установки и не считайте его автоматически совместимым с canonical node-updater только по наличию checksum-sidecar. Исправленный runtime publication contract применяется к последующим квалифицированным Stable-релизам; опубликованный v0.56.0 не изменялся задним числом.

## Перед установкой

1. Скачайте официальный `home-center-0.56.0-source.tar.gz` и `SHA256SUMS` из публичного Stable-релиза 0.56.0.
2. Проверьте SHA-256 source-архива по `SHA256SUMS`. При несовпадении остановите установку.
3. Подготовьте конфигурацию схемы, поддерживаемой выпуском, и отдельные TLS-идентичности для Web-доступа и межузлового взаимодействия, если используется multi-node профиль.
4. Проверьте свободное место, синхронизацию времени, DNS и наличие резервного административного доступа к серверу.
5. Для существующей установки сначала создайте проверяемую резервную копию состояния и конфигурации; для чистого узла заранее определите recovery/rollback-путь.

## Установка

Распакуйте source-архив, перейдите в его корневой каталог и сначала выполните staging без активации:

```bash
sudo bash deploy/scripts/install.sh --config /path/to/config.json
```

Установщик проверяет release identity и структуру артефакта, создаёт версионированный каталог в `/opt/home-center/releases`, проверяет конфигурацию и подготавливает системную учётную запись/каталоги. На этапе staging текущая активная версия не переключается.

Проверьте конфигурацию, systemd units, пути сертификатов, права на секреты и возможность отката. Только после успешной проверки активируйте выпуск:

```bash
sudo bash deploy/scripts/install.sh --config /path/to/config.json --activate
```

Активация атомарно переключает `/opt/home-center/current`. Если основные сервисы не запускаются успешно, установщик пытается вернуть предыдущую активную версию.

## После установки

Проверьте:

- `home-center.service` и связанные необходимые сервисы;
- release identity `0.56.0`;
- Web-доступ по HTTPS и readiness/health;
- доступность state DB и конфигурации;
- backup readiness;
- отсутствие критических ошибок и деградации peer-связности для multi-node профиля.

Не публикуйте административные интерфейсы наружу без предусмотренного защищённого контура. Примеры конфигурации являются шаблонами: не используйте демонстрационные адреса, имена, пути, пароли или ключи без адаптации к своей среде.

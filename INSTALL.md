# Установка Home Center 0.51.0

Home Center 0.51.0 требует Linux, systemd, Python 3.12 или новее, SQLite и подготовленных оператором TLS-идентификаторов.

Перед установкой:

1. загрузите артефакт только из официального Stable release;
2. проверьте `SHA256SUMS` и встроенный `MANIFEST.sha256`;
3. проверьте `VERSION`, `REVISION`, release manifest и acceptance evidence;
4. убедитесь, что пути сертификатов, storage и rollback prerequisites подготовлены.

Базовая установка выполняется через штатный установщик из релизного архива:

`sudo bash deploy/scripts/install.sh --config /path/to/config.json`

Сначала новая версия размещается в отдельном неизменяемом каталоге. Параметр `--activate` следует использовать только после проверки конфигурации и prerequisites. При активации указатель `current` переключается атомарно; если сервисы не запускаются успешно, должен быть восстановлен предыдущий target.

Не копируйте примерные значения конфигурации без проверки. Публикация Stable-релиза не является автоматическим разрешением на production-активацию.
